1. Cargar los datos familiares

Selecciona el archivo familia.json que utilizas actualmente. Los cambios se mantienen en esta sesión hasta que exportes el archivo actualizado. Esta página no modifica GitHub directamente.

2. Registrar familiar

Los IDs existentes se conservan. En nuevos registros se asigna automáticamente el siguiente identificador disponible. El cumpleaños debe escribirse como DD-MM.

Selecciona a un familiar existente o registra un cónyuge nuevo.

Se creará un registro independiente con el siguiente ID disponible. Después podrás completar sus demás datos.

Selecciona padre y madre únicamente cuando el parentesco esté confirmado. El sistema guarda sus IDs, no solo sus nombres.

3. Directorio de familiares

Puedes buscar por nombre, ID, ciudad o país. Antes de eliminar un familiar, el sistema comprobará si otros registros lo tienen asociado como padre o madre.

Carga primero familia.json.

4. Publicar los cambios

Cuando termines, selecciona “Validar y descargar JSON”. El archivo exportado será una nueva copia de trabajo. Para publicar los cambios, tendrás que subirlo a GitHub en la ruta data/familia.json. No reemplaces el archivo original hasta haber revisado la exportación.
